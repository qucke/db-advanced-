## Таблица calc.standard_heights
Справочник стандартных высот бюллетеня «Метео-11». Общий узел
для связки всех расчётных справочников. Высоты > 4000 и < 200 по алгоритму
копируются из 4000 и 200 соответственно, поэтому в справочнике не хранятся.

## Таблица calc.height_temperature_deviations
Хранит матрицу средних отклонений температуры. Строка = (высота Y, составляющая
отклонения). Значение коррекции хранится уже со знаком: отрицательное = числитель
бумажной дроби, положительное = знаменатель. Составляющая хранится разложенно
(единицы и десятки), чтобы алгоритм собирал любое отклонение суммой
двух строк.

## Таблица calc.height_wind_average_speeds (Таблица 3 - скорость ветра)
Хранит скорости среднего ветра Wy для обоих типов оборудования. Входной параметр
хранится в колонке input_value с привязкой к equipment_type_id:
- equipment_type_id=1 (ДМК): input_value = скорость приземного ветра V0
- equipment_type_id=2 (ВР): input_value = дальность сноса пуль Дг

Строки с граничными значениями (V0 < 3 для ДМК, Дг < 40 для ВР) заполнены
нулями явно, чтобы выборка была однородной.

## Таблица calc.height_wind_angles (Таблица 3 - приращение угла)
Хранит приращения дирекционного угла ветра Δα_WY для обоих типов оборудования.
Приращение угла зависит только от типа оборудования и высоты, а НЕ от
входного параметра, поэтому хранится в отдельной таблице с ключом
(equipment_type_id, height).
